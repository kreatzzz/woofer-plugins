Woofer Plugins

Sandboxed additions for Woofer, the fast native Spotify client. Every plugin here runs inside a WebAssembly sandbox: it can compute, and it can ask Woofer to fetch only from the domains it declares — nothing else. Every listing is reviewed by hand before it appears.

Installing

  1. Download a plugin's .wasm file below.
  2. In Woofer, open the Plugins page from the top bar.
  3. Drag the file onto the window — or paste its address under Install from URL.
  4. Toggle it on. Translate and Romanize ship inside Woofer already; a downloaded plugin with the same job replaces your pick on the Plugins page.
The catalog lives at github.com/kreatzzz/woofer-plugins — propose a plugin with a pull request; nothing is listed without a reviewed merge. Woofer is not affiliated with Spotify.
