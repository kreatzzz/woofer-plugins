# Offline Romanizer

Writes non-Latin lyric lines with printable ASCII characters using AnyAscii's
Unicode tables. It runs entirely inside Woofer's Wasm sandbox and asks for no
network access.

Source and tests live in
[`plugins/romanize-offline`](https://github.com/kreatzzz/woofer/tree/main/plugins/romanize-offline).
The bundled AnyAscii tables use the ISC license recorded beside the source.
