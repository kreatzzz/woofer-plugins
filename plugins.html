Plugins

Sandboxed additions for Woofer. Every plugin here runs inside a WebAssembly sandbox: it can compute, and it can ask Woofer to fetch only from the domains it declares — nothing else. Every listing is reviewed by hand before it appears. Open in Woofer hands the install to the running app; the link needs Woofer running to find it.

Installing

  1. Press Open in Woofer on a card — the running app asks for a confirmation and installs. (Woofer must be running.)
  2. Or download a plugin's .wasm, open the Plugins page from the top bar, and drag the file onto the window.
  3. Or paste its address under Install from URL.
  4. Toggle it on. Data capabilities are single-active: installing a second provider never silently replaces your first — the Plugins page asks which one you want.
The catalog lives at github.com/kreatzzz/woofer-plugins — propose a plugin with a pull request; nothing is listed without a reviewed merge. Woofer is not affiliated with Spotify.
